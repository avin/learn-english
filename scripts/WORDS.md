# Словари уроков

Скрипт читает PDF с названиями, содержащими «словарь», из папок
`Титановый/<уровень>/<номер урока>` и создаёт `words.json` рядом с
`tasks.json` соответствующего урока. Уроки без словарей пропускаются;
для курса «Экспресс» словарей в исходных материалах нет. PDF без
соответствующего урока перечисляются в выводе и не создают новые уроки.

Нужны Python 3 и утилита `pdftotext` из Poppler, доступная в PATH.

```powershell
python scripts/import-words.py --dry-run
python scripts/import-words.py
```

По умолчанию исходные материалы берутся из `F:/Английский по плейлистам`.
Другой путь можно передать через `--source`, а путь к утилите — через
`--pdftotext`. Повторный запуск перезаписывает созданные `words.json`.

Каждая запись содержит последовательный `id`, поля `ru.text` и `en.text`,
исходную транскрипцию в `en.transcription` и `audio: false` для обоих языков.
Нумерация в JSON не зависит от возможных пропусков и ошибок нумерации в PDF.
Слова без номера тоже извлекаются. Если строка PDF не распознана, скрипт
завершается с ошибкой до записи каких-либо файлов.
