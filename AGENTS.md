# Правила работы в проекте

- Делай только запрошенное. Сохраняй существующий интерфейс и поведение, кроме прямо запрошенных изменений.
- Если добавляешь новый способ управления, сначала проверь поведение существующего аналога и воспроизведи его, включая крайние случаи.
- Не добавляй тексты, подсказки, настройки или новые сценарии по своей инициативе.
- Если из запроса и текущего кода следует один вариант, действуй без подтверждения. Если остаются несколько вариантов с заметно разным результатом, задай один конкретный вопрос.
