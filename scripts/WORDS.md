# Словари уроков

`scripts/import-words.py` проверяет PDF в материалах «Титанового» и «Экспресса».
Он извлекает отдельные словари и разделы под заголовком «Слова к уроку» внутри
PDF с заданиями, затем создаёт `words.json` в папке соответствующего урока.
Например, словарь первого урока «Титанового» находится в рабочей тетради.
Уроки без словарей пропускаются. Если папки урока ещё нет, скрипт создаёт её
для словаря; `tasks.json` при этом не создаётся.

Нужны Python 3 и утилита `pdftotext` из Poppler, доступная в PATH.

```powershell
python scripts/import-words.py --dry-run
python scripts/import-words.py
```

По умолчанию материалы берутся из `F:/Английский по плейлистам`. Другой путь
можно передать через `--source`, а путь к утилите — через `--pdftotext`.
Существующие словари и флаги аудио сохраняются. Если содержимое словаря
отличается от исходного PDF, скрипт сообщает об этом и ничего не перезаписывает.

Каждая запись содержит последовательный `id`, поля `ru.text` и `en.text`,
исходную транскрипцию в `en.transcription` и `audio: false` для обоих языков.
Нумерация в JSON не зависит от возможных пропусков и ошибок нумерации в PDF.
Слова без номера тоже извлекаются. Если строка PDF не распознана, скрипт
завершается с ошибкой до записи каких-либо файлов.
